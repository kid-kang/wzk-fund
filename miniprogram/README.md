# WZK Fund · 微信小程序

原生微信小程序客户端，与仓库内行情代理共用同一计算口径；持仓 / 自选 / 黄金 / 开关保存在本机 `wx.storage`（键名 `wzk-fund-config`）。

> 仅供个人体验，默认不发布上架。计算逻辑与免责声明见仓库根目录 [README.md](../README.md)。更多截图见根目录 [界面预览](../README.md#界面预览)。

### 近期能力

| 能力 | 说明 |
|------|------|
| 持仓操作账本 | 左滑「操作」：持仓信息 / 加仓 / 减仓 / 定投；净值未公布则待确认；减仓快捷 1/4～3/4、清仓 |
| 删除持仓 vs 自选 | 持仓删除清交易/定投/买卖点并转入自选，收益记录保留；自选删除只移出自选 |
| 名称检索 | 添加持仓/自选可输入名称或代码片段，点选后写入 6 位代码（`GET /api/funds/suggest`） |
| 交易 / 收益记录 | 「我的」进入：交易流水与按日组合盈亏 |
| 净值曲线标记 | 图例始终显示；高低点同色白圈标涨跌幅；买入/卖出/清仓只画色点 |

## 功能模块

### Tab 栏（单壳页）

首页为 `pages/main/main`：自定义底栏 + 页内切换内容（**不用**原生 `tabBar` / `wx.switchTab`，避免真机切 Tab 闪白）。

| Tab | 组件 | 说明 |
|-----|------|------|
| 持仓 | `components/tab-holdings` | 基金持仓汇总与列表，可选黄金模块 |
| 自选 | `components/tab-watchlist` | 自选基金列表 |
| 行情 | `components/tab-market` | A 股涨跌家数、主力资金、板块榜、基金榜、指数网格 |
| 我的 | `components/tab-mine` | 显示开关、主题、账本入口、Q&A、API、配置导入导出 |

深色主题下底栏图标与配色会随主题切换。

---

### 持仓

**组件**：`components/tab-holdings`（挂载于壳页）

- **汇总**：基金持仓总金额、当日收益、当日收益率；眼睛图标可隐藏金额（本地键 `holdings_hide_amounts`）
- **列表**：名称（过长跑马灯）、金额、仓位占比、当日盈亏 / 涨跌幅、板块标签（最多 2 个）、净值已确认徽章、迷你估值走势
- **黄金**（可关）：总价值、收益、收益率、实时金价；与基金汇总分开计算
- **交互**：分区标题旁 `+` 添加持仓；左滑 **操作**（进加减仓/定投页）/ **删除**（清掉该基金交易、定投、买卖点并转入自选，收益记录保留；系统确认框）；点名称或迷你图进基金详情；点金价进金价走势；点设置进黄金编辑
- **刷新**：约 30s 静默轮询

---

### 自选

**组件**：`components/tab-watchlist`（挂载于壳页）

- 列表：名称、涨跌幅、板块、确认徽章、迷你走势
- 导航标题动态为 `自选(N)`
- 右下角 **FAB `+`** 添加自选；左滑删除（只移出自选，交易记录和买卖点保留）
- 点名称或迷你图进基金详情
- 约 30s 静默轮询

---

### 行情

**组件**：`components/tab-market`（挂载于壳页）

- **涨跌温度**：涨 / 跌家数占比
- **主力资金**：沪深主力净流入水位
- **板块 / 基金榜**：热搜、涨幅等；点板块进热搜基金页
- **指数网格**：上证、深证、创业板、北证50、科创50、上证50、沪深300、中证500、纳斯达克100、标普500 等；点卡片进指数走势
- 约 30s 静默轮询

---

### 我的

**组件**：`components/tab-mine`（挂载于壳页）

| 区块 | 功能 |
|------|------|
| 显示 | 黄金持仓开关；隐藏金额；深色主题 |
| 账本 | **收益记录**（按天盈亏）；**交易记录**（加仓/减仓/定投流水） |
| 接口 | API Base 输入 / 保存；「探测连通」请求 `/api/health`，状态灯提示 |
| 配置 | **导出**：整份 JSON 到剪贴板；**导入**：从剪贴板读 JSON 写入本地；可清空持仓 / 自选 / 全部 |
| 说明 | **Q&A**：口径与常见问题 |

背景水印 `wzk-fund`（Archivo Black）。页底免责声明。账本两项进入二级页。

---

### 基金表单（二级）

**路径**：`pages/fund-form/fund-form`

| 模式 | 入口 | 字段 |
|------|------|------|
| `hold` | 持仓 `+` | 代码或名称、当前持仓金额、投入成本、买入日期（选填） |
| `watch` | 自选 FAB | 代码或名称 |

代码框支持 **6 位代码** 或 **名称检索**（输入两个字以上或 2～5 位代码片段出现候选，点选后填入代码）。满 6 位自动 `resolve` 名称；持仓保存时按确认净值反推份额。金额/成本输入会过滤非数字。已在持仓中的基金不能再添加。编辑持仓改为走「操作」页，表单时代码可锁定。

---

### 持仓操作（二级）

**路径**：`pages/fund-ops/fund-ops`  
**入口**：持仓左滑「操作」

| Tab | 说明 |
|-----|------|
| 持仓信息 | 持仓金额、投入成本、收益率只读；买入日期可改 |
| 加仓 | 买入金额、费率、申请时段（15:00 前/后）；净值未公布则待确认 |
| 减仓 | 卖出份额；快捷 1/4、1/3、1/2、2/3、3/4、清仓；卖出日不得早于买入日 |
| 定投 | 金额、费率、周期；改周期生成新计划；可暂停 / 终止 |

确认按钮有二次弹窗。QDII 与境内同一套 15:00 切点，等申请日净值。页内可看该基金操作记录。

---

### 交易记录 / 收益记录（二级）

| 页面 | 路径 | 入口 | 说明 |
|------|------|------|------|
| 交易记录 | `pages/trade-log/trade-log` | 我的 · 交易记录 | 加仓、减仓、清仓、定投流水；待确认会标出 |
| 收益记录 | `pages/profit-log/profit-log` | 我的 · 收益记录 | 功能上线后按天记下的组合盈亏；删除单只持仓不会清掉 |

---

### 基金详情（二级）

**路径**：`pages/fund-trend/fund-trend`  
**入口**：持仓 / 自选名称或迷你图

- 报头：`代码 · 名称` + 成立时长（如「成立3年2月」）+ 可点板块 + 自选/持有状态
- 周期胶囊：近1月 / 近3月 / 近6月 / 近1年 / 近3年 / 成立来；下方红绿区间涨跌幅
- 成立不足对应时长则隐藏周期；「成立来」始终保留
- 图例始终显示：高低点（同色深褐、白圈、标涨跌幅）、买入 / 卖出 / 清仓（色点，不标涨跌幅，避免每日定投过密）
- 高低点标注、净值 tooltip、「来财 / 進寶」水印；各周期预取缓存
- 下方看板：重仓股 / 历史净值 / 阶段涨跌 / 最大回撤 / 规模

---

### 黄金设置（二级）

**路径**：`pages/gold-edit/gold-edit`  
**入口**：持仓黄金区设置图标

- 买入/卖出费率、持有克数、成本均价（元/克）
- 黄金只维护持仓口径，不记加仓减仓流水
- 「来财」装饰区

---

### 金价走势（二级）

**路径**：`pages/gold-trend/gold-trend`  
**入口**：持仓「实时金价」

- 报头：AU9999 · 沪金99 + 当前金价
- 周期：分时 / 近1月 / 近3月 / 近6月 / 近1年
- 价格轴 + 高低点；切换周期先卸旧图；「来财」水印

---

### 指数走势（二级）

**路径**：`pages/index-trend/index-trend`  
**入口**：行情指数卡片

- 样式对齐基金走势详情（报头、周期胶囊、红绿涨跌、高低点、来财水印）
- 周期：近1月 / 近3月 / 近6月 / 近1年 / 近3年
- tooltip 展示收盘价；各周期预取缓存

---

### 板块热搜基金（二级）

**路径**：`pages/sector-funds/sector-funds`  
**入口**：行情板块行；持仓 / 自选 / 基金详情的板块标签

该板块相关热搜基金列表；可加自选；点行进基金详情；跟随深浅色主题。

---

### Q&A（二级）

**路径**：`pages/fund-qa/fund-qa`  
**入口**：「我的」；持仓 / 自选徽章；添加持仓说明

口径与常见问题（A 股确认、QDII 延迟、加仓规则等）。带 `q=` 时展开对应条目。

## 本地存储

| 键 | 说明 |
|----|------|
| `wzk-fund-config` | `settings` / `funds` / `gold` / `profitLog` / `trades` / `sipPlans` |
| `wzk-fund-api-base` | 代理地址；未设置时默认 `https://wzk-fund.uk`，本地开发可改为 `http://127.0.0.1:8787` |
| `wzk-fund-theme` | `light` / `dark` |
| `holdings_hide_amounts` | 持仓金额是否隐藏 |

## 启动与真机

1. 仓库根目录启动代理：`npm run dev:server`（默认 `:8787`）
2. 安装依赖并打包 Vant：

```bash
cd miniprogram
npm install
```

3. 用[微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)导入本目录
4. **详情 → 本地设置 → 不校验合法域名、web-view（…）**
5. 编译运行；「我的」可改 API 并探测连通

真机调试：手机与电脑同一 Wi‑Fi，API 改为电脑局域网 IP（如 `http://192.168.x.x:8787`），防火墙放行 8787。`127.0.0.1` 仅模拟器可用。

## 技术要点

| 项 | 说明 |
|----|------|
| UI | Vant Weapp（swipe-cell / field / switch / empty / toast 等） |
| 图表 | ECharts（`components/ec-canvas` + `ec-line`：spark / trend） |
| 金额精度 | `decimal.js`（对齐支付宝口径）；表单数字输入过滤非数字 |
| 主题 | `utils/theme.js` 同步原生导航栏与窗口底色（无原生 TabBar） |
| 架构 | 单壳页 `pages/main` + 自定义底栏 + 四个 Tab 组件，页内 `setData` 切换 |

